# 사건별 꿀팁 실습 예시 (전부 가상)

강의 「사건별 꿀팁」 슬라이드의 지시문을 그대로 실행해 볼 수 있는 가상 자료다. 실제 인물·사건·계좌와 관계없다.

| 폴더 | 쓰는 꿀팁 | 파일 |
|---|---|---|
| 민사 | 금융거래정보 제출명령, 회신 거래내역 → 엑셀, 법원 양식 채우기 | 사건정보.md, 금융거래정보회신_신한은행.pdf(스캔본), 양식/주소보정서_A1138(hwp·hwpx) |
| 형사 | 증거기록 쪼개기, 증거인부서 표, 열람·등사 신청서, 접견 준비 | 사건정보.md, 증거목록.pdf, 증거기록_교부본.pdf(스캔본, 순번 7 빠짐), 양식/열람등사신청서_별지제220호.hwpx |
| 가사 | 상속재산 목록·가액표, 주민등록초본 발급 신청, 의뢰인 안내문, hwp → hwpx 변환(S28-1) | 사건정보.md, 등기사항증명서 2건, 공시가격_조회결과.pdf, 예금잔액증명서_국민은행.pdf, 양식/주민등록표_교부신청서_별지제7호.hwpx, 양식/재산목록_가사(hwp·hwpx) |

`양식/` 폴더의 서식은 빈 공식 서식이다. hwp는 원본, hwpx는 kordoc으로 서식 그대로 바꾼 파일이다. `_원본.pdf`는 채운 결과와 쪽수·배치를 대조하는 용도다.
- 출처: 주소보정서(전산양식 A1138)·재산목록 — 대한민국 법원 전자소송포털 양식모음
- 출처: 열람ㆍ등사ㆍ서면교부 신청서 — 국가법령정보센터, 공소청사건사무규칙 별지 제220호서식(2026. 10. 1. 공포본)
- 출처: 주민등록표 열람 또는 등ㆍ초본 교부 신청서 — 국가법령정보센터, 주민등록법 시행규칙 별지 제7호서식(2026. 4. 28. 공포본)

지연손해금·기한 계산, 가사비송 서면 규칙은 예시 파일 없이 지시문만으로 된다.

## 정답 확인용
- 민사 거래내역: 시작 잔액 2,350,000원(2013. 1. 1. 이전 잔액), 거래 37건, 마지막 잔액 38,919,910원. 김민철 입금 4건(합계 90,000,000원), 김민철 앞 출금 3건(합계 10,000,000원).
- 형사 증거기록: 기록 총 29면. 증거목록 순번 1~10 중 순번 7(수사보고, 계좌추적 결과, 기록 19~21쪽)이 교부본에 없다(쪽수가 18쪽에서 22쪽으로 건너뛴다).
- 가사 상속재산(공시가격 2025. 1. 1. 기준): 마포구 아파트 812,000,000원, 양평군 임야 70,950,000원(3,300㎡ × ㎡당 21,500원), 예금 85,240,000원(35,240,000원 + 50,000,000원). 양평군 임야에 근저당권(채권최고액 60,000,000원)이 있다. 마포구 아파트의 근저당권은 2014. 3. 4. 말소됐다.
